# Native presentation adapter

`MoirasiaUI` exposes shared semantic colors, dimensions, motion and typography for SwiftUI. `MoiraTokens.swift` is generated by `@moirasia/design-system`; edit the canonical foundation or product source, then run root `pnpm ui:preset:sync` and `pnpm ui:preset:check`.

MoiraColor follows native light/dark appearance, including alpha. Surface stays distinct from canvas in both modes. Dimensions use points, and motion uses seconds. MoiraControl adds largeHeight and touchHeight while preserving smallHeight and mediumHeight; mobile controls should use touchHeight or native platform minimums, not the compact desktop size.

MoiraType preserves all seven methods and their weight/design parameters. macOS uses the authored point scale. iOS uses semantic system text styles so SwiftUI Dynamic Type scales with the environment. Neither platform loads a web font. App-level accessibility, focus and reduced-motion behavior remain native.

MoiraExithibition intentionally remains fixed-dark; structural names resolve to common dark roles and telemetry names to product dark data. Existing public exports, including windowBackground, remain available even without current callers.

Verify with `swift test --package-path packages/ui-swift` plus Semiquaver's macOS/iOS Xcode tests and rendered presentation checks. The Node packaging tests in Semiquaver do not test native rendering.
