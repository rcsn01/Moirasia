# Plain CSS presentation adapter

Generated by `@moirasia/design-system` from the shared foundation. Do not edit foundation.css or themes/*.css by hand. Use root `pnpm ui:preset:sync` and `pnpm ui:preset:check`.

Import `@moirasia/ui-css/foundation.css` once for an OS-adaptive workspace. Existing product entrypoints remain available:

- `litemaptica.css`: fixed dark structural roles plus confidence visualization colors.
- `mini-nsw.css`: fixed light structural roles plus a simulation timeline marker.
- `exithibition.css`: fixed dark structural roles plus telemetry colors.
- `amove.css` and `openagent.css`: compatibility entrypoints inheriting adaptive shared roles. No current app imports these.

Consume semantic `--moira-*` names. Product colors do not redefine ordinary action, focus, radius or type roles. Fixed themes select all semantic colors and shadows independently of OS appearance; reduced-motion preferences still zero motion durations.

foundation.css imports `@fontsource/actor` `^5.3.0` for the main font and `@fontsource-variable/jetbrains-mono` `^5.3.0` for monospace text, declared by this package and licensed under SIL OFL 1.1. Bundlers emit its font files locally; no CDN or OS-installed font is required. Local file dependencies in Bun/npm can omit or incompletely resolve transitive dependencies, so LiteMaptica and Mini-NSW explicitly declare the same font dependency and lock its version. Refresh their local ui-css package copies after generation and verify development and built font loading.

App-specific DOM layouts, canvas sizing, scene colors and workflow behavior remain in their owning apps. This package does not impose desktop-shell layout rules on plain-CSS or mobile consumers.
